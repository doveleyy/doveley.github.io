TME Bucket Percentile Overlay

Primary plot

The working view is the petal plot: each TME score petal bulges by its axis percentile, and the buckets inside it divide that petal by share, so the bucket values in a score always total 100%. Bucket percentiles are shown only as baseline bars in the legend.

Organic tumour shape divided into four quadrants whose boundary bulges by TME score, with gene-set buckets dividing each quadrant by share

Bucket share overlay

Bucket share inputs

These sliders set each bucket's share input in the data's own units. Shares are always redrawn as value divided by the score total, so the quadrant stays at 100% whatever the inputs are.

Rationale

  • Bucket wedges span their score petal's radius and take an angular slice of the quadrant, so a bucket is contained within its TME score petal by construction and can never draw outside it.
  • Wedge width is the bucket's share of the score total, so the buckets in a quadrant sum to exactly 100%. Displayed percentages use largest-remainder rounding so they never print 99% or 101%.
  • Bucket percentile to baseline is no longer encoded by petal size or repeated as another score number. It is shown as a small baseline bar with a tick at the 50th percentile, which separates "how much of the score is this bucket" from "how does this bucket compare with the baseline cohort".
  • Share inputs are held in one place per bucket, so bucket-level normalised values can replace the raw bucket scores without any change to the geometry.
  • Bucket percentiles are used instead of raw bucket scores for the baseline comparison because absolute scores scale strongly with bucket size.
  • Raw percentage-contribution shares look very similar across patients, so they are poor at showing patient-specific differences.
  • The legend sits outside the plot so bucket names, share values and baseline bars can stay aligned without covering the petals.
