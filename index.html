TME Bucket Tumour Plot

A patient-level view of the tumour microenvironment scores and the gene-set buckets inside them. A faint grey full-scale tumour shows the 100th-percentile extent; coloured lobes fill it to each TME score percentile, with dashed arcs marking the TME 50th percentile. Inside, bucket percentiles are rebased into relative signals that add to 100%.

These sliders set each bucket's percentile against the cohort. The plot rebases those values within each TME lobe into relative signals that add to exactly 100%.

How To Read It

  • The faint full-scale silhouette is the 100th-percentile extent of the four TME scores. Coloured lobes fill it to the selected patient's score percentile for Angiogenesis, Immunogenicity, Fibrosis and EMT; the dashed arc in each lobe marks that TME score's 50th percentile.
  • Inside each lobe, every bucket gets an equal angular slot. The bucket percentiles are rebased within that lobe, producing relative signals that add to 100%. The largest relative signal reaches the outer score envelope and the remaining petals are proportional to it.
  • Relative signal shows a bucket's prominence in this patient's percentile pattern; it is not raw-score contribution or variance explained. The baseline bar retains the original bucket percentile against the GC PD-1 harmonised cohort, with its centre tick at the 50th percentile.
  • Percentiles are used instead of raw bucket scores because absolute scores scale strongly with bucket size, so raw values are poor at showing patient-specific differences.
  • The legend outside the plot lists each bucket name with its percentile value, so names and numbers stay on one line without covering the petals.
