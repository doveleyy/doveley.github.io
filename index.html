Rationale

  • Bucket percentiles are used instead of raw bucket scores because absolute scores scale strongly with bucket size.
  • Raw percentage-contribution petals look very similar across patients, so they are poor at showing patient-specific differences.
  • The legend sits outside the plot so bucket names and percentile values can stay on one line without covering the petals.
  • Bucket colours stay within each score family, using the same ramps as the contribution examples for consistency.
